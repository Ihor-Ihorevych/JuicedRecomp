# Juiced (Xbox 2005), statically recompiled for Android

Port of Juiced using the XboxXBERecomp SDK, same approach as RatatouilleRecomp. Needs your own copy of the game: extract the disc to game_files/, copy default.xbe to assets/, build tools-build, then run android/build-apk.sh --recomp. See android/README.md.

Status: builds an arm64 APK; untested on a device. This repository holds no game files or game code.
